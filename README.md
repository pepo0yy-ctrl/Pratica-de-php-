# Sistema de Cadastro Simples

Projeto estudantil desenvolvido para prática de **HTML** e **PHP**, focado em criar um formulário e processar os dados enviados.

## 📁 Arquivos do Projeto
- `cadastro.html`: Formulário com campos de nome, idade, profissão, salário e experiência.
- `processaCadastro.php`: Arquivo que recebe os dados via POST, armazena em variáveis e exibe na tela.

## 🚀 Como Rodar
1. Instale um servidor local (ex: **XAMPP**, **WAMP** ou **Laragon**).
2. Coloque os dois arquivos na pasta do servidor (ex: `htdocs` ou `www`).
3. Acesse no navegador: `http://localhost/nome-da-pasta/cadastro.html`.
4. Preencha o formulário e clique em "Enviar".

## ⚙️ Funcionalidades
- Recebe dados via método **POST**.
- Armazena cada dado em uma variável PHP.
- Exibe as informações formatadas com HTML.
- Mostra uma mensagem personalizada ao final.
- Botão para retornar ao formulário.

## 🎯 Objetivo do Projeto
Demonstrar compreensão sobre:
- Estrutura de formulários HTML.
- Coleta e manipulação de dados com PHP (`$_POST`).
- Uso de funções de segurança (`htmlspecialchars`).
- Lógica de programação básica.

> **Nota**: O foco é a lógica de programação. O CSS é básico, mas pode ser melhorado.
